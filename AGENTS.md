# AGENTS.md

`tauri-plugin-fontgres` is a Tauri v2 plugin: the Rust crate in `src/` serves the commands, and the npm package built from `guest-js/` calls them. Font loading, listing and matching belong to [fontgres-core](https://github.com/seferino-fernandez/fontgres); this crate only adapts it to Tauri, so font behaviour changes land there.

## Quality gates

1. Run `just verify` before finishing, and finish only when it passes (mirrored by `.github/workflows/pull-request-validation.yml`).
2. Fix the code a lint flags. When the code is right as written, put `#[expect(lint, reason = "…")]` on the item and name the invariant that makes it right; `#[allow]` fails the gate (Clippy `allow_attributes`).
3. Keep every test meaningful: when a test looks wrong, stop and say so instead of deleting, ignoring or weakening it.
4. Pin each workflow action to a full commit SHA followed by a `# vX` comment.
5. Write commit messages as conventional commits (`feat:`, `fix:`, `chore(deps):`…).

## Keep these in step

- **A command** is listed in `build.rs` (`COMMANDS`), registered in `src/lib.rs`, defined for desktop and mobile in `src/commands.rs`, allowed in `permissions/default.toml`, and wrapped in `guest-js/index.ts`. The files under `permissions/autogenerated/` and `permissions/schemas/` regenerate on build; commit them.
- **The JSON shapes.** `Face` (`src/face.rs`) and `Error` (`src/error.rs`) are typed by hand in `guest-js/index.ts`. The serialization tests in `src/fonts.rs` and `src/error.rs` pin the JSON; change them and the TypeScript types together.
- **The version.** `Cargo.toml` and `package.json` always carry the same version; the release workflow refuses a tag that does not match both ([docs/releasing.md](docs/releasing.md)).
