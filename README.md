# tauri-plugin-fontgres

A [Tauri v2](https://v2.tauri.app) plugin that lists the fonts installed on the system and answers CSS-style font queries about them, built on [fontgres](https://github.com/seferino-fernandez/fontgres).

- **Every face, with what CSS needs:** family and subfamily names, PostScript name, weight, style, stretch, monospacing, file path and collection index.
- **CSS font matching:** give families in priority order with a weight, style and stretch, and get back the best match by the CSS font matching rules. A generic name such as `sans-serif` stands for one family (Arial, for example), not a fallback list.
- **Loaded once:** the fonts are read on the first call and kept until you call `reload()`.

## Platform support

| Platform | Supported |
| -------- | --------- |
| Windows  | ✅        |
| macOS    | ✅        |
| Linux    | ✅        |
| Android  | ❌        |
| iOS      | ❌        |

On Android and iOS every command rejects with `kind: "unsupportedPlatform"`.

## Install

Requires Rust 1.100 or newer.

```shell
cargo add tauri-plugin-fontgres
pnpm add tauri-plugin-fontgres-api
```

Register the plugin in `src-tauri/src/lib.rs`:

```diff
pub fn run() {
    tauri::Builder::default()
+       .plugin(tauri_plugin_fontgres::init())
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

Allow its commands in `src-tauri/capabilities/default.json`:

```diff
{
    ...
    "permissions": [
        ...
+       "fontgres:default"
    ]
}
```

`fontgres:default` allows every command. To allow only some, list `fontgres:allow-get-faces`, `fontgres:allow-get-families`, `fontgres:allow-query-face` and `fontgres:allow-reload` instead ([permission reference](permissions/autogenerated/reference.md)).

## Usage

```ts
import { getFaces, getFamilies, isFontgresError, queryFace, reload } from "tauri-plugin-fontgres-api";

// Every face, sorted by family, then weight, style, stretch and PostScript name
const faces = await getFaces();

// The faces of one family (matched ignoring ASCII case)
const helvetica = await getFaces({ family: "Helvetica Neue" });

// The family names, sorted
const families = await getFamilies();

// The best face for font-family: "Helvetica Neue", sans-serif; font-weight: 700
try {
  const face = await queryFace({ families: ["Helvetica Neue", "sans-serif"], weight: 700 });
  console.log(face.postScriptName, face.path);
} catch (error) {
  if (isFontgresError(error) && error.kind === "noMatch") {
    // none of the families is installed
  }
}

// Pick up fonts installed or removed while the app runs
await reload();
```

### Commands

| Function | Returns |
| -------- | ------- |
| `getFaces({ family? })` | `Face[]`: every face, or those of one family |
| `getFamilies()` | `string[]`: the distinct family names |
| `queryFace({ families, weight?, style?, stretch? })` | `Face`: the best match by the CSS font matching rules. `weight` defaults to 400, `style` and `stretch` to `"normal"` |
| `reload()` | Reads the system fonts again |

A `Face` is:

```ts
interface Face {
  family: string;          // primary family name, such as "Helvetica Neue"
  families: string[];      // every family name, in every language, primary first
  subfamily: string;       // such as "Bold Italic"; empty when the font has none
  postScriptName: string;
  style: "normal" | "italic" | "oblique";
  weight: number;          // 1 to 1000; 400 is normal, 700 bold
  stretch: "ultra-condensed" | "extra-condensed" | "condensed" | "semi-condensed" | "normal"
         | "semi-expanded" | "expanded" | "extra-expanded" | "ultra-expanded";
  monospaced: boolean;
  path: string | null;     // the font file
  index: number;           // position within a collection (.ttc) file
}
```

A command's own failures reject with `{ kind, message }`, where `kind` is `noFamilies`, `weightOutOfRange`, `noMatch` or `unsupportedPlatform`; `isFontgresError` tells them apart. Tauri itself rejects invalid arguments (an unknown style keyword, say) and missing permissions with a plain string.

Families whose name starts with `.` (Apple's private system UI faces, such as `.SF NS`) are left out: CSS cannot use them by name.
